# sebermedical.com

Webbplatsen för Seber Medical och Funktion:Sår, publicerad med GitHub Pages.

- `index.html` – hela webbplatsen (Version F). Formulären skickas till Wix Forms på Wix-sajten DermaCut.
- `about/`, `contact/`, `woundresearch/`, `sv/…` – omdirigeringar från den gamla Wix-sajtens adresser.
- `404.html` – okända adresser skickas till startsidan.
